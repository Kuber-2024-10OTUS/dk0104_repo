** Argocd installation
- Argocd helm chart aus der [[id:https://yandex.cloud/en/docs/managed-kubernetes/operations/applications/argo-cd][yandex einleitun]]g pullen  und eigene values setzen
  #+begin_src shell
   helm pull oci://cr.yandex/yc-marketplace/yandex-cloud/argo/chart/argo-cd --version 7.3.11-2 --untar
  #+end_src


- Helm chart einstellungen setzen damit nur ein node verwendet wird
  #+begin_src yaml
  global:
    tolerations:
    - key: "node-role"
      operator: "Equal"
      value: "infra"
      effect: "NoSchedule"
    # Default affinity preset for all components
    affinity:
      nodeAffinity:
        requiredDuringSchedulingIgnoredDuringExecution:
          nodeSelectorTerms:
          - matchExpressions:
            - key: node-role
              operator: In
              values:
              - "infra"
  #+end_src

- Helm chart installieren
  #+begin_src shell
  helm install --namespace argocd --create-namespace argocd .
  #+end_src
